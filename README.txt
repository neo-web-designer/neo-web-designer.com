# NEO WEB DESIGNER — redesigned website

This is a clean, responsive replacement website for GitHub Pages.

## Files
- `index.html` — page content and sections
- `style.css` — NEO neon color system and responsive layout
- `script.js` — mobile navigation, current year, and copy-contact buttons

## Publish on GitHub Pages
1. Extract this ZIP.
2. Open your GitHub repository for the website.
3. Upload `index.html`, `style.css`, and `script.js` to the repository root (same folder as the existing site's main `index.html`).
4. Replace the existing files when GitHub asks, then commit the changes.
5. In the repository, open **Settings → Pages** and confirm the publishing source/branch is the one you use (usually `main` and `/(root)`).
6. Wait for GitHub Pages to finish publishing, then refresh the live website.
